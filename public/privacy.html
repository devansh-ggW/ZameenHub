Privacy Policy

How CinderClip handles information in the current experimental product.

Last updated: September 27, 2026

CinderClip is an experimental video-processing product. This Privacy Policy explains what information CinderClip handles in the current product and how that approach may change as hosted features are added.

The current local MVP uses temporary session storage on the machine running CinderClip. Files are intended to exist only for the active browser session and are automatically cleaned up when the session ends; browser/app failures may delay cleanup until the next session or an automatic stale-file cleanup pass.

1. Information CinderClip may handle

Video files. When a user selects a video for processing, the current local MVP receives the file through the local CinderClip server so it can read metadata and generate output.

Project information. The current MVP may use information such as the original filename, duration, dimensions, selected output settings, and generated clip metadata as part of processing.

Technical information. A future hosted version may receive standard technical information needed to operate the service, such as request data, device/browser information, security logs, and error information. The exact categories will be documented before that release.

2. How information is used

  • To process and generate requested video outputs.
  • To keep the application working, secure, and reliable.
  • To diagnose errors and improve the product.
  • For additional purposes only when clearly described when the relevant feature is introduced.

3. Storage and deletion

In the current local MVP, uploaded source files and generated clips are temporary working files stored on the machine running CinderClip. Starting a fresh browser session clears files from previous sessions, and leaving or refreshing the page attempts to clean up the active session. An automatic stale-file cleanup is also used as a fallback for interrupted sessions. Users should download anything they want to keep before ending the session.

The production hosted storage architecture has not been finalized, so future hosted retention rules may differ and this policy will be updated before that release.

4. Sharing

CinderClip is not intended to sell uploaded video content. A future hosted product may use infrastructure or service providers needed to operate processing, storage, authentication, payments, or monitoring.

5. User responsibility

Do not upload content unless you are permitted to process it. Users should avoid uploading highly sensitive or confidential material to experimental versions of the product.

6. Changes

This policy may be updated when CinderClip adds hosted processing, accounts, analytics, payments, or other features.
